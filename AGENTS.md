# Repository Language

- Use English for all repository-authored content, including documentation, specifications,
  checklists, comments, identifiers, examples, test fixtures, UI copy, and error messages.
- Use English names for files and directories. Write commit messages in English.
- Keep all future repository changes in English; do not introduce Portuguese prose or examples.
- Preserve proper names, external identifiers, URLs, and character fixtures required for
  protocol compatibility or correct program behavior.
